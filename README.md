# סקריפט להחלפת Utilman

סקריפט Batch זה נועד להחליף או לשחזר את הקובץ `utilman.exe` בקובץ `cmd.exe` בתיקיית `Windows\System32` של הכונן שבו הסקריפט נמצא, והוא מותאם לשימוש בסביבת **מסוף השחזור של Windows (WinRE)**. הסקריפט מאפשר פתיחת שורת פקודה ממסך הכניסה של Windows על ידי הפעלת כלי הנגישות, ומאפשר גם שחזור הקובץ המקורי מגיבוי. כל ההודעות המוצגות על ידי הסקריפט הן באנגלית לתאימות עם מסוף השחזור.

⚠️ **אזהרה**: סקריפט זה משנה קבצי מערכת ויכול לשמש לעקיפת מנגנוני אבטחה (כגון גישה לשורת פקודה ממסך הכניסה). השתמשו בו **אך ורק בסביבת בדיקה מבוקרת** ועם אישור מתאים. שימוש לא נכון עלול לגרום לחוסר יציבות במערכת או לפרצות אבטחה.

## מאפיינים

- פעולה על הכונן שבו נמצא הסקריפט (למשל, `E:\Windows\System32` אם הסקריפט ב-`E:`).
- בדיקת סביבת WinRE באמצעות `WINDIR` ו-`explorer.exe` למניעת הרצה ב-Windows פעיל.
- יצירת גיבוי של `utilman.exe` לפני ההחלפה.
- החלפת `utilman.exe` בקובץ `cmd.exe` מתוך אותה תיקייה.
- שחזור הקובץ `utilman.exe` מגיבוי לפי הצורך.
- הודעות קונסולה באנגלית לתאימות עם תצוגה במסוף השחזור.
- תמיכה בהודעות צבעוניות (ירוק, צהוב, אדום; תמיכה מוגבלת ב-WinRE).
- תאימות לסביבת מסוף השחזור של Windows.

## דרישות

- מערכת Windows עם גישה לסביבת מסוף השחזור (WinRE).
- כונן USB או דיסק נגיש המכיל את הסקריפט, המונח בכונן שבו נמצאת מערכת ההפעלה.
- ידע בסיסי בתפעול שורת הפקודה וקבצי מערכת של Windows.
- יש להריץ את הסקריפט מתוך **שורת הפקודה** בסביבת WinRE.

## התקנה

1. שכפלו או הורידו את המאגר למחשב המקומי או לכונן USB:

   ```bash
   git clone https://github.com/<שם-המשתמש-שלך>/utilman-toggle-script.git
   ```

ודאו שהקובץ toggle_utilman_cmd.bat נמצא על הכונן שבו מותקנת מערכת ההפעלה (למשל, E: אם תיקיית Windows\System32 נמצאת שם).

הוראות שימוש
אתחול לסביבת מסוף השחזור

הכניסו מדיית התקנה של Windows או אתחלו למצב התקדמות מתקדם (Advanced Startup).

נווטו ל: פתרון תקלות > אפשרויות מתקדמות > שורת הפקודה.

הרצת הסקריפט

בשורת הפקודה של WinRE, נווטו לכונן שבו נמצא הסקריפט (למשל, E:).

הריצו את הסקריפט:

E:\toggle_utilman_cmd.bat

התנהגות הסקריפט

בודק אם הסקריפט רץ בסביבת WinRE. אם לא, מציג אזהרה ויוצא.

בודק אם תיקיית Windows\System32 וקובץ utilman.exe קיימים בכונן של הסקריפט.

אם קיים utilman_backup.exe בתיקיית System32:

משחזר את utilman.exe מהגיבוי ומוחק את הגיבוי.

אם קיים utilman.exe ואין גיבוי:

יוצר גיבוי (utilman_backup.exe) ומחליף את utilman.exe בקובץ cmd.exe.

אם לא נמצא utilman.exe או cmd.exe:

מציג הודעת שגיאה ויוצא.

לאחר ההחלפה

אתחלו מחדש את המערכת. לחיצה על כפתור הנגישות (או הקשה על Win+U) במסך הכניסה תפתח את cmd.exe.

כדי לשחזר את הקובץ המקורי utilman.exe, הריצו את הסקריפט שוב ב-WinRE.

דוגמה לפלט
[INFO] cmd.exe found in E:\Windows\System32\
[WARNING] utilman.exe found, creating backup and replacing with cmd.exe...
[DONE] Replacement completed.

הערות

הסקריפט פועל רק על הכונן שבו הוא נמצא (למשל, E:), ומצפה שתיקיית Windows\System32 תהיה זמינה באותו כונן.

כל ההודעות מוצגות באנגלית כדי להבטיח תאימות עם תצוגת מסוף השחזור.

הפקודה color להצגת הודעות צבעוניות עשויה להיות מוגבלת בסביבת WinRE, תלוי בגרסת Windows.

ודאו שיש לכם גיבוי מלא של המערכת לפני שינוי קבצי מערכת.

אזהרות

יציבות המערכת: החלפת utilman.exe עלולה לגרום לבעיות בתכונות הנגישות או ביציבות המערכת. השתמשו בזהירות.

סיכוני אבטחה: החלפת utilman.exe ב-cmd.exe עשויה לאפשר גישה לא מורשית למערכת (למשל, עקיפת מסך הכניסה). השתמשו בסקריפט זה באחריות ורק בסביבות שבהן יש לכם הרשאה מפורשת.

סביבת בדיקה: מומלץ לבדוק את הסקריפט במכונה וירטואלית או בסביבה שאינה יצרנית תחילה.
